To-Do List is an application where users can add tasks they need to complete and choose their priority (high, medium, or low).

The project is built using PyQt5, and the UI is designed in Qt Designer, which is converted to Python using pyuic5.

The user manually enters the task name, selects its priority, and adds it to the list. The user can also mark tasks as completed and view the number of completed tasks. If needed, the list can be cleared as well.
